## Sitio publicado

El despliegue de cPanel copia las páginas HTML y sus recursos desde la raíz del repositorio. Para revisar esa versión en local, ejecuta `python -m http.server 4173` y abre `http://127.0.0.1:4173/`.

`python sitegen.py` genera los borradores de HTML y el sitemap a partir de `content/` dentro de `.sitegen/`. Revisa las diferencias antes de incorporar contenido generado a las páginas publicadas.
